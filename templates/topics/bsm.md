# Topic: High-Energy Physics BSM Phenomenology (from hep-ph)

## Filtering Policy (STRICT)
- **Keep ONLY** papers focused on Beyond the Standard Model (BSM) phenomenology, including:
  - Dark Matter models, direct/indirect detection, cosmological abundance
  - Axions / ALPs / Dark Photons / Feebly Interacting Particles
  - SMEFT / HEFT / EFT global fits and new-physics bounds
  - SUSY, Composite Higgs, extra dimensions, extended Higgs sectors
  - BSM neutrino physics (seesaw, sterile neutrinos, NSI)
  - Baryogenesis / Leptogenesis, early-universe phase transitions & gravitational waves
  - BSM collider phenomenology (LHC, FCC, HL-LHC, long-lived particles) and BSM flavor anomalies
  - Any other topic that is DEFINITELY BSM phenomenology but not listed above
- **Exclude**:
  - Pure Standard Model precision QCD/EW calculations, PDF fits, jet substructure without BSM focus
  - Pure hadron spectroscopy / heavy-ion QGP physics
  - Conference proceedings, whitepapers without new results, and PhD theses

## Highlight Selection Criteria
Prioritize papers that introduce novel BSM mechanisms, derive strong new experimental/astrophysical constraints, recast recent LHC/direct-detection data, or release public phenomenology tools (FeynRules, MadGraph, UFO models, etc.).

## Deep-Dive Requirements
For each highlighted paper, extract:
1. Motivation & specific BSM model / EFT operators studied.
2. Experimental datasets, collider channels, or astrophysical probes used.
3. Exact quantitative bounds / reach / significance (with energy scales, masses, couplings).
4. Public code / GitHub links if available.

## Output Format
- Sections:
  1. `# BSM Phenomenology Daily Digest` + date
  2. `## Frontier Trends` (2–4 sentences summarizing today's themes)
  3. `## Highlighted Papers` (deep dives)
  4. `## Other BSM Papers` (one-line summary + link per remaining paper)
